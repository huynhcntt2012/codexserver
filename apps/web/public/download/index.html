Cài đặt

  1. Tải file .zip ở trên.
  2. Giải nén vào một thư mục bất kỳ.
  3. Mở suni-bot-arena.exe trong thư mục vừa giải nén. Nếu Windows SmartScreen cảnh báo, chọn “Thông tin thêm” → “Vẫn chạy”.

Cấu hình đề nghị

Windows 10/11 64-bit · Card đồ họa hỗ trợ OpenGL 3.3 / Vulkan · 4 GB RAM · 200 MB trống · Kết nối Internet để chơi online.

Kiểm tra file

So mã SHA-256 bằng PowerShell: Get-FileHash .\ten-file.zip. Mã phải trùng với mã hiển thị ở trên.
