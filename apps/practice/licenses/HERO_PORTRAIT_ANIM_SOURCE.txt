# Animated hero portraits (idle loop)

Source: one sheet image of the five heroes in six idle poses (1448x1086,
opaque WebP on a flat #333e4f background with drop shadows), supplied by the
project owner in a Claude Code session on 2026-10-21, kept at
`tools/source/hero_portraits_idle.webp` (338546 bytes).
SHA-256: c9fa5541abcb700ed63d5650cd4105f3e312bcc7a0821b5279bdb3cbad5a08ce
It replaces a hop sheet supplied on 2026-10-20, which is no longer used.

Rows match the project's heroes (blue boy = bombo, pink girl = mimi, red boy =
zin, golden girl = lala, green boy = kai); columns are one idle loop: stand,
laugh, stand, wink, giggle, stand. It looks like image-generator output made
for this project's heroes; its origin and rights were not independently
verified, and it carries no author, name, logo or text from Boom Online.
Confirm ownership before a commercial release.

`tools/slice_hero_portraits.gd` turned the flat background into transparency
(the drop shadows and anti-aliased edges into soft alpha, un-composited from
the background colour), split the grid at its emptiest pixel columns and, per
column, rows; kept each cell's figure and scaled each hero's frames by one
factor into `assets/characters/portraits/<hero>/01-06.png` (160x160). No
pixels were painted. The still `<hero>.png` portraits stay as the fallback.
